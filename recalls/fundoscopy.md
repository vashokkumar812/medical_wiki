| --------------------------------------- | ----------------------------------------------------------------------------- | ---------------------------- |
| Central retinal artery occlusion (CRAO) | **Cherry-red spot + pale retina** ![[Pasted image 20260616001255.png]]        | Ocular stroke                |
| Central retinal vein occlusion (CRVO)   | **Blood-and-thunder retina** ![[Pasted image 20260616001318.png]]             | Dilated tortuous veins       |
| Branch retinal artery occlusion (BRAO)  | **Sectoral retinal whitening** ![[Pasted image 20260616001350.png]]           | Branch artery occlusion      |
| Early diabetic retinopathy              | **Microaneurysms** ![[Pasted image 20260616001444.png]]                       | Earliest diabetic change     |
| Non-proliferative diabetic retinopathy  | **Dot-blot haemorrhages + hard exudates**![[Pasted image 20260616001522.png]] | Diabetes                     |
| Proliferative diabetic retinopathy      | **Neovascularisation**                                                        | Advanced diabetes            |
| Hypertensive retinopathy                | **AV nicking + copper/silver wiring** ![[Pasted image 20260616001842.png]]    | Chronic hypertension         |
| Malignant hypertension                  | **Flame-shaped haemorrhages + papilloedema**                                  | Hypertensive emergency       |
| Primary open-angle glaucoma             | **Optic disc cupping (↑ cup-to-disc ratio)**                                  | Glaucoma                     |
| Papilloedema                            | **Blurred optic disc margins (bilateral)**                                    | Raised intracranial pressure |
| Dry age-related macular degeneration    | **Drusen**                                                                    | Dry AMD                      |

| Feature                  | **CRAO**                                                        | **BRAO**                                  | **CRVO**                                             |
| ------------------------ | --------------------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------- |
| **Onset**                | Sudden                                                          | Sudden                                    | Sudden/subacute                                      |
| **Vision loss**          | Severe, painless, monocular                                     | Partial visual field loss                 | Variable, painless                                   |
| **Pain**                 | None                                                            | None                                      | None                                                 |
| **Fundoscopy**           | Pale retina + **cherry-red spot**                               | Sectoral retinal whitening                | **Blood-and-thunder retina**                         |
| **Distribution**         | Entire retina                                                   | Branch retinal territory                  | Entire retina                                        |
| **Macula**               | Cherry-red spot                                                 | May be involved if branch supplies macula | Macular oedema common                                |
| **Retinal haemorrhages** | Minimal                                                         | Minimal                                   | Extensive (all quadrants)                            |
| **Cotton-wool spots**    | Rare                                                            | Rare                                      | Common                                               |
| **Retinal veins**        | Normal                                                          | Normal                                    | Dilated, tortuous                                    |
| **Retinal arteries**     | Attenuated                                                      | Branch occluded                           | Normal                                               |
| **Pupillary defect**     | RAPD common                                                     | May occur                                 | May occur (severe)                                   |
| **Common risk factors**  | Carotid disease, AF, emboli, GCA                                | Emboli, carotid disease                   | HTN, DM, glaucoma                                    |
| **Key investigation**    | ESR/CRP if >50 (exclude GCA), carotid imaging                   | Carotid assessment                        | OCT ± fluorescein angiography                        |
| **Emergency?**           | **Yes**                                                         | **Yes**                                   | Urgent ophthalmology                                 |
| **Initial management**   | Immediate ophthalmology, stroke work-up, treat GCA if suspected | Urgent ophthalmology, embolic work-up     | Ophthalmology referral, anti-VEGF for macular oedema |
| **Major complication**   | Permanent blindness                                             | Persistent field defect                   | Neovascular glaucoma                                 |

# POAG vs PACG (AMC MCQ High-Yield)

| Feature              | Primary Open-Angle Glaucoma (POAG)                                    | Primary Angle-Closure Glaucoma (PACG)                                                                                   |
| -------------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Onset                | Gradual, chronic                                                      | Sudden (acute) or chronic                                                                                               |
| Pathophysiology      | Reduced aqueous outflow through trabecular meshwork                   | Closure of anterior chamber angle blocks aqueous drainage                                                               |
| Risk factors         | Age, family history, African ancestry, diabetes, myopia, ↑IOP         | Age, female, Asian ethnicity, hyperopia, shallow anterior chamber                                                       |
| Symptoms             | Usually asymptomatic until late; gradual peripheral vision loss       | Severe eye pain, headache, nausea/vomiting, blurred vision, halos around lights                                         |
| Vision loss          | Progressive peripheral → tunnel vision                                | Rapid visual loss if untreated                                                                                          |
| Eye redness          | Usually absent                                                        | Marked conjunctival injection                                                                                           |
| Cornea               | Clear                                                                 | Hazy/steamy (corneal oedema)                                                                                            |
| Pupil                | Normal                                                                | Mid-dilated, fixed, poorly reactive                                                                                     |
| IOP                  | Elevated (or normal in normal-tension glaucoma)                       | Markedly elevated (often >40–50 mmHg)                                                                                   |
| Gonioscopy           | Open angle                                                            | Closed/narrow angle                                                                                                     |
| Optic disc           | Increased cup-to-disc ratio                                           | Increased cupping if prolonged                                                                                          |
| Visual field         | Peripheral defects                                                    | May be normal initially; permanent defects if delayed treatment                                                         |
| Diagnosis            | Tonometry + optic nerve assessment + OCT + visual fields + gonioscopy | Clinical diagnosis + tonometry + gonioscopy (after IOP reduced)                                                         |
| Initial treatment    | Prostaglandin analogue (e.g. latanoprost)                             | Medical emergency: acetazolamide + topical timolol + apraclonidine/brimonidine ± pilocarpine (after IOP starts falling) |
| Definitive treatment | Long-term topical therapy ± laser trabeculoplasty/surgery             | Laser peripheral iridotomy (both affected and fellow eye)                                                               |
| Emergency?           | No                                                                    | Yes – ophthalmology emergency                                                                                           |
