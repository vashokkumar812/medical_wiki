| Feature             | **Serotonin Syndrome (SS)**                                                                                  | **Neuroleptic Malignant Syndrome (NMS)**                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| **Cause**           | Excess serotonin (SSRI, SNRI, MAOI, tramadol, linezolid, MDMA)                                               | Dopamine blockade/withdrawal (antipsychotics, metoclopramide, levodopa withdrawal)                      |
| **Onset** ⭐         | **Rapid** (hours; <24 h)                                                                                     | **Gradual** (1–3 days; up to 2 weeks)                                                                   |
| **Mental state**    | Agitation, anxiety, confusion                                                                                | Confusion, delirium, stupor                                                                             |
| **Neuromuscular** ⭐ | **Hyperreflexia**, **clonus**, tremor, myoclonus                                                             | **Lead-pipe rigidity**, hyporeflexia/normal reflexes, bradykinesia                                      |
| **Autonomic**       | Hyperthermia, diaphoresis, tachycardia, hypertension, **mydriasis**, **diarrhoea**, hyperactive bowel sounds | Hyperthermia, diaphoresis, tachycardia, labile BP, **normal pupils**, **normal/decreased bowel sounds** |
| **Laboratory**      | Mild–moderate ↑CK, mild ↑WBC                                                                                 | **Marked ↑CK**, ↑WBC, rhabdomyolysis, AKI                                                               |
| **Treatment** ⭐     | Stop serotonergic drug → Supportive care + benzodiazepines + **Cyproheptadine**                              | Stop antipsychotic → Supportive care + **Dantrolene** or **Bromocriptine**                              |

### AMC Rapid Memory

- **Serotonin Syndrome = FAST + HYPER**
	- **Fast onset**
	- **Hyperreflexia**
	- **Clonus**
	- Tremor
	- Diarrhoea
	- Dilated pupils
	- **Cyproheptadine**

- **Neuroleptic Malignant Syndrome = SLOW + STIFF**
	- **Slow onset**
	- **Lead-pipe rigidity**
	- **Very high CK**
	- Normal/decreased reflexes
	- Recent antipsychotic
	- **Dantrolene/Bromocriptine**
