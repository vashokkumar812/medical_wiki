# Acute Upper Airway Obstruction (Paediatrics) (AMC MCQ High-Yield)

- **Key Principles**
	- **Do NOT upset the child**
	- Allow child to sit in **position of comfort**
	- Keep with parent
	- Minimal examination
	- Airway obstruction can deteriorate rapidly
	- Call senior help early (ENT/Anaesthetics)

- **Severity Assessment**

	- **Mild**
		- + Barking cough/hoarse voice
		- + Intermittent stridor
		- + Minimal work of breathing
		- + Good air entry

	- **Moderate**
		- + Continuous stridor
		- + Tachypnoea
		- + Moderate work of breathing
		- + Nasal flaring
		- + Reduced air entry

	- **Severe**
		- + Tripod/sniffing position
		- + Marked work of breathing
		- + Hypoxia (late sign)
		- + Agitated or drowsy
		- + Poor/no air entry
		- + Silent chest = impending respiratory arrest

- **Emergency Management**
	- Keep child calm
	- Oxygen if tolerated
	- **Nebulised adrenaline**
		- Temporary airway relief
	- **Dexamethasone 0.6 mg/kg (max 16 mg)** PO/IM/IV
	- Prepare for difficult airway
	- Early ENT/Anaesthetic involvement
	- Avoid unnecessary IV access or investigations until airway secure

# Differential Diagnosis (AMC Comparison)

| Condition | Key Clinical Features |
|-----------|-----------------------|
| **Croup** | + Age 6 months–3 years + Barking cough + Hoarse voice + Inspiratory stridor + Low-grade fever + Child usually not toxic |
| **Epiglottitis** | + High fever + Toxic appearance + Drooling + Dysphagia + Muffled voice + Tripod position + **No cough** + Do **NOT** examine throat |
| **Bacterial Tracheitis** | + High fever + Toxic child + Recent viral URTI + Thick purulent secretions + Poor response to adrenaline |
| **Retropharyngeal Abscess** | + Fever + Neck pain + Torticollis + Drooling + Dysphagia + Bulging posterior pharyngeal wall |
| **Peritonsillar Abscess (Quinsy)** | + Severe unilateral sore throat + Hot potato voice + Trismus + Uvula deviated away from affected side |
| **Anaphylaxis** | + Sudden onset + Facial/lip swelling + Urticaria + Wheeze + Hypotension + Allergen exposure |
| **Foreign Body Aspiration** | + Sudden choking episode + Cough + Stridor/wheeze + Unilateral chest findings |
| **Ludwig Angina** | + Dental infection + Floor of mouth swelling + Tongue elevation + Neck swelling |
| **Airway Burn** | + Facial burns + Singed nasal hairs + Soot in mouth + Hoarseness |
| **Trauma** | + Neck injury + Bruising + Subcutaneous emphysema |

# Investigations

- **Croup**
	- No investigations required

- **Moderate/Severe obstruction**
	- Avoid investigations until airway secured

- Imaging (only if stable)
	- Neck X-ray
	- Chest X-ray
	- CT (selected cases)

---

# Treatment Summary

| Condition | First-line Treatment |
|-----------|----------------------|
| Mild croup | Oral dexamethasone |
| Moderate/Severe croup | **Nebulised adrenaline + dexamethasone** |
| Epiglottitis | Secure airway + IV ceftriaxone/cefotaxime |
| Bacterial tracheitis | Airway support + IV antibiotics |
| Anaphylaxis | **IM adrenaline** |
| Foreign body | Rigid bronchoscopy |
| Retropharyngeal abscess | IV antibiotics ± surgical drainage |
| Peritonsillar abscess | Drainage + antibiotics |

# AMC Pearls

- **Most common cause of acute upper airway obstruction = Croup.**
- **Drooling + tripod position + no cough = Epiglottitis until proven otherwise.**
- **Barking cough = Croup.**
- **Hot potato voice + uvular deviation = Peritonsillar abscess.**
- **Neck stiffness/torticollis + posterior pharyngeal swelling = Retropharyngeal abscess.**
- **Nebulised adrenaline provides temporary relief only.**
- **Dexamethasone should be given to children with croup.**
- **Do NOT attempt throat examination in suspected epiglottitis.**
- **A silent chest or absent air movement indicates impending complete airway obstruction.**
