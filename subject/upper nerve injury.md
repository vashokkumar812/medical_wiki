# Upper Limb Nerve Lesions (AMC MCQ High-Yield)

| Lesion                              | Clinical Features                                                                                                                                                                                                                               |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| thoracic outlet syndrome            | Cervical rib : **Pain** + **Paresthesia** + **Weakness** (ulnar side of hand) + **Hand muscle wasting** + **Coldness/Pallor** + **Diminished radial pulse** (especially on arm abduction) + **Supraclavicular swelling/tenderness**.            |
| C8–T1 Radiculopathy                 | + Weak finger flexion + Weak finger abduction/adduction + Hand grip weakness + Sensory loss medial forearm + medial hand (C8/T1 dermatomes) + Reduced finger flexion reflexes (if severe) + May have neck pain radiating to arm                 |
| Axillary Nerve Injury               | + Weak shoulder abduction (15–90°) + Deltoid wasting + Weak external rotation + Sensory loss over lateral shoulder ("regimental badge" area) + Reduced deltoid contour                                                                          |
| Radial Nerve Injury (Spiral Groove) | + Wrist drop + Finger drop + Weak thumb extension + Weak elbow extension (mild) + Sensory loss dorsal first web space + Triceps reflex usually preserved (or mildly reduced)                                                                    |
| Ulnar Nerve Injury (Elbow)          | + Ulnar claw (4th & 5th digits, **less clawing**) + Weak finger abduction/adduction + Positive Froment sign + Weak grip + Sensory loss little finger + medial half of ring finger + Wasting of interossei + FDP to ring/little finger also weak |
| Ulnar Nerve Injury (Wrist)**        | + **More pronounced ulnar claw** (4th & 5th digits) + Finger abduction/adduction weakness + Positive Froment sign + Sensory loss little finger + medial half of ring finger + Interossei wasting + FDP preserved                                |
| carpel tunnel syndrome              | lateral 3.5 fingers sensation lost, aggravated on sleep due to flexing on hand, due to median nerve, wasting of thenar muscles, weakness of thumb muscles                                                                                       |

## AMC Pearls
- **C8–T1 lesion** → Includes **medial forearm** sensory loss (not just hand).
- **Ulnar nerve at elbow** → Less clawing because **FDP is also paralysed** ("ulnar paradox").
- **Ulnar nerve at wrist** → More clawing because FDP is intact.
- **Radial nerve (spiral groove)** → Wrist drop + preserved elbow extension.
- **Axillary nerve** → Shoulder dislocation or surgical neck fracture → Deltoid weakness + regimental badge numbness.
