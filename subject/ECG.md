| Component   | Definition                                                                      | Normal Values / Notes                                      |
| ----------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| P wave      | Atrial depolarization                                                           | —                                                          |
| PR interval | Time from start of atrial depolarization to start of ventricular depolarization | 120–200 ms                                                 |
| QRS complex | Ventricular depolarization                                                      | < 100 ms                                                   |
| QT interval | Ventricular depolarization, mechanical contraction, and repolarization          | —                                                          |
| T wave      | Ventricular repolarization                                                      | Inversion → ischemia or recent MI                          |
| J point     | Junction between end of QRS complex and start of ST segment                     | —                                                          |
| ST segment  | Isoelectric phase; ventricles are depolarized                                   | —                                                          |
| U wave      | Seen after T wave                                                               | Prominent in hypokalemia (“hypo**U**kalemia”), bradycardia |
