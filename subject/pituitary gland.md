| hormone      | function                                                                     |                                                                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADH          | - increase water permiability in DCT and collecting duct cells               | stimulus for secretion is increased plasma osmolality (except SIADH)                                                                                                      |
| CRH          | increase ACTH, MSH, Beta endorphin                                           | decreased in chronic glucocorticoid use                                                                                                                                   |
| dopamine     | decrease prolactin, TSH                                                      | dopamine antagonists ( antipshycotics ) ==> hyperprolactnemia ==> galactorrhea                                                                                            |
| GHRH         | increase growth hormone                                                      | Analog ( tesamorelin ) ==> treat HIV associated lipodystrophy                                                                                                             |
| GnRH         | increased FSH, LH                                                            | suppressed by hyperprolactinemia; tonic GNRH analog (leupolide) supress HPG axis; pulsatile GnRH leads to puberty, fertility                                              |
| MSH          | increase melanogenesis by melanocytes                                        | MSH and ACTH has same precursor molecule prooplomelanocortin ==> hyperpigmentation in cushing disease                                                                     |
| oxytocin     | causes uterine contractions, milk letdown reflex ( in response to suckling ) | modulates fear, anxiety, social bonding, mood, depression                                                                                                                 |
| prolactin    | decrease GnRH, promotes lactogenesis                                         | pitutary prolactinoma ==> amenorrhea, osteoporosis, hypogonadism, galactorrhea ; breast feeding ==> increase prolactin ==> decrease GnRH ==> delayed postpartum ovulation |
| somatostatin | decrease GH, TSH                                                             | also called growth hormone inhibiting hormone; analogs used to treat acromegaly                                                                                           |
| TRH          | increase TSH, prolactin                                                      | increase TRH ==> increase prolactin ==> glactorrhea                                                                                                                       |
