


# chronic pancreatitis
Uncommon cause of chronic UAP
	
		- Features
			- Steatorrhoea
				- Late finding
	
		- Causes
			- Alcohol most common
	
		- Diagnostic clues
			- Pancreatic calcification
			- Previous pancreatitis
			- Heavy alcohol use
			- Duct obstruction
	
		- Lipase/imaging may be normal

# pancreatic malignancy
Features
			- Insidious pain
			- Weight loss
			- Anorexia
			- Jaundice
	
		- Investigations
			- Ultrasound
				- Detects biliary dilatation
				- Poor tumour sensitivity
	
			- CT abdomen
			- ERCP
			- MRI
