- Dementia

	- Definition
		- Progressive decline in memory plus ≥1 other cognitive domain
		- Causes impairment in social or occupational functioning
		- Cognitive domains affected
			- Memory
			- Language
			- Executive function
			- Visuospatial skills
			- Praxis
			- Attention

- Causes

	- Reversible (always exclude first)
		- Depression (pseudodementia)
		- Hypothyroidism
		- Vitamin B12 deficiency
		- Drug-induced (especially anticholinergics)
		- Normal pressure hydrocephalus (NPH)
		- Subdural haematoma
		- Brain tumour
		- Neurosyphilis
		- HIV
		- Sleep apnoea
		- Hepatic encephalopathy
		- Uraemia

	- Irreversible
		- ⭐ Alzheimer's disease (60–80%; most common)
		- Vascular dementia
		- Dementia with Lewy bodies (DLB)
		- Frontotemporal dementia (Pick disease)
		- Parkinson disease dementia
		- Creutzfeldt-Jakob disease (CJD)

- Clinical Features

	- General
		- Progressive memory impairment
		- Difficulty performing daily activities
		- Language impairment
		- Executive dysfunction
		- Personality or behavioural changes

	- Mild Cognitive Impairment (MCI)
		- Memory impairment only
		- No functional impairment
		- Increased risk of Alzheimer's disease

- Major Dementia Types (AMC Comparison)

| Dementia | Key distinguishing features |
|----------|-----------------------------|
| **Alzheimer disease** ⭐ | Most common; gradual onset; early episodic memory loss; visuospatial dysfunction; aphasia/apraxia/agnosia later; hallucinations late |
| **Vascular dementia** | Stepwise decline; focal neurological deficits; history of stroke/CVD |
| **Lewy body dementia** | Fluctuating cognition; recurrent visual hallucinations; spontaneous parkinsonism; marked neuroleptic sensitivity |
| **Parkinson disease dementia** | Established Parkinson disease precedes dementia (>1 year); visual hallucinations common |
| **Frontotemporal dementia (Pick disease)** | Early personality and behavioural change; disinhibition; language dysfunction; memory relatively preserved initially |
| **Normal pressure hydrocephalus** | **Triad:** gait disturbance → urinary incontinence → dementia; ventriculomegaly; normal CSF pressure |
| **Creutzfeldt-Jakob disease** | Rapid progression (weeks–months); myoclonus; ataxia; 14-3-3 protein in CSF |

- Initial Assessment

	- History
		- Onset and progression
		- Functional decline
		- Medication review
		- Mood symptoms
		- Alcohol/drug history
		- Family history

	- Examination
		- Full neurological examination
		- Cognitive assessment
			- MMSE
			- MoCA (more sensitive for early disease)

- Initial Investigations (Rule Out Reversible Causes)

	- FBC
	- UEC/Creatinine
	- LFT
	- Blood glucose
	- Calcium
	- TSH
	- Vitamin B12
	- Folate (often included)
	- Syphilis serology (RPR/VDRL)
	- HIV (if risk factors)

- Imaging

	- CT brain or MRI brain
		- New focal neurological deficits
		- Early onset (<65 years)
		- Rapid progression
		- Gait disturbance
		- Seizures
		- Suspicion of tumour, stroke or NPH

	- Special tests
		- CSF 14-3-3 protein → suspected CJD
		- Lumbar puncture → NPH (diagnostic tap test)

- Management

	- General
		- Exclude reversible causes
		- Optimise vascular risk factors
		- Medication review
		- Cognitive stimulation
		- Occupational therapy
		- Physiotherapy
		- Carer education and support
		- Advance care planning
		- Driving assessment

	- Pharmacological

		- Mild to moderate Alzheimer's disease
			- ⭐ Donepezil
			- Rivastigmine
			- Galantamine

		- Moderate to severe Alzheimer's disease
			- ⭐ Memantine
			- May combine with cholinesterase inhibitor

		- Behavioural symptoms
			- Non-pharmacological first
			- Antipsychotics only if severe distress or danger

- Drug Summary

| Drug | Indication |
|------|------------|
| **Donepezil** ⭐ | First-line mild–moderate Alzheimer's disease |
| Rivastigmine | Mild–moderate Alzheimer's disease; Parkinson dementia |
| Galantamine | Mild–moderate Alzheimer's disease |
| **Memantine** ⭐ | Moderate–severe Alzheimer's disease |

- High-Yield AMC Pearls

	- ⭐ Alzheimer's disease = most common cause of dementia.
	- ⭐ Always exclude reversible causes before diagnosing dementia.
	- ⭐ MMSE or MoCA = initial cognitive assessment.
	- ⭐ Donepezil = first-line drug for mild–moderate Alzheimer's disease.
	- ⭐ Memantine = moderate–severe Alzheimer's disease.
	- ⭐ Lewy body dementia = fluctuating cognition + recurrent visual hallucinations + parkinsonism.
	- ⭐ Vascular dementia = stepwise deterioration.
	- ⭐ Frontotemporal dementia = early behavioural/personality change.
	- ⭐ NPH = gait disturbance + urinary incontinence + dementia ("Wet, Wobbly, Wacky").
	- ⭐ CJD = rapidly progressive dementia + myoclonus.
