# Stevens–Johnson Syndrome (SJS) / Toxic Epidermal Necrolysis (TEN)

- Definition
	- Rare, severe, potentially fatal hypersensitivity reaction characterized by:
		- Epidermal necrosis
		- Blistering
		- Extensive skin loss

- Classification by body surface area (BSA)

| Condition | Skin involvement |
|---|---|
| SJS | <10% BSA |
| SJS/TEN overlap | 10–30% BSA |
| TEN | >30% BSA |

- Pathogenesis
	- Immune-mediated keratinocyte apoptosis

- Common triggers
	- Sulfonamide antibiotics
		- Sulfamethoxazole
		- Sulfadiazine
	- Antiepileptic drugs
		- Carbamazepine
		- Lamotrigine
	- Allopurinol
	- Oxicam NSAIDs

- Major causes of death
	- Sepsis
	- Hypovolaemia
	- Electrolyte imbalance
	- Renal failure

- Clinical features
	- Prodrome
		- Fever
		- Malaise
		- URTI symptoms
	- Skin lesions
		- Dusky red macules
		- Patches
		- Blisters
		- Mucositis
		- skin tenderness
	- Positive Nikolsky sign
		- Indicates compromised epidermal structural integrity

	- Systemic manifestations
		- Lymphadenopathy
		- Hepatitis
		- Cytopenias
		- Cholestasis

- Differential diagnosis

| Disorder                                     | Aetiology                                       | Clinical features                                                                               |
| -------------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| SJS/TEN                                      | Drug reaction                                   | Prodromal illness 1–3 days before rash, skin tenderness, dusky red macules, blisters, mucositis |
| Erythema multiforme (EM)                     | Infection (90%), often HSV                      | Typical target lesions, in EM Major ==> severe mucosal involvement                              |
| Staphylococcal scalded skin syndrome (SSSS)  | Exfoliative toxins from *Staphylococcus aureus* | Mainly affects children <5 years, fever, irritability, skin desquamation                        |
| Mycoplasma-induced rash and mucositis (MIRM) | *Mycoplasma pneumoniae* infection               | Severe mucositis with minimal skin involvement                                                  |
| TEN-like lupus erythematosus                 | Autoimmune                                      | Lupus with TEN-like features                                                                    |
| Pemphigus                                    | Autoimmune                                      | Flaccid vesicles and erosions                                                                   |
| Pemphigoid                                   | Autoimmune                                      | Tense vesicles and blisters                                                                     |

- Investigations
	- Histopathology
		- Extensive full-thickness epidermal necrosis
		- Scant perivascular lymphocytic infiltrates
		- Direct immunofluorescence negative

- Management
	- Key principles
		1. Immediate referral to emergency department
		2. Discontinue offending drug
		3. Transfer to burns unit if severe
		4. Supportive care
			- Fluid and electrolyte balance
			- Infection prevention
			- Wound care
			- Pain control
			- Nutritional support
	
	- Possible immunomodulatory treatments
		- Systemic corticosteroids
		- IVIG
		- Cyclosporine
		- Etanercept

- Prevention strategies
	- Permanent avoidance of offending medication
	- Clear documentation of drug allergy
	- Communication with primary physician

- Genetic screening
	- Certain HLA types increase risk

| Medication    | Gene variant |
| ------------- | ------------ |
| Abacavir      | HLA-B*5701   |
| Allopurinol   | HLA-B*5801   |
| Carbamazepine | HLA-B*1502   |
| Carbamazepine | HLA-B*3101   |
| Lamotrigine   | HLA-B*1502   |
| Lamotrigine   | HLA-B*4403   |

- Example
	- HLA-B*1502 testing in Asian populations reduces carbamazepine-induced SJS/TEN
