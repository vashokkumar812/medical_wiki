- Cervical lymphadenopathy (child)

- Key points
    - Common finding
        - Palpable in >1/3 healthy children
    - Well-appearing child
        - Observation + reassurance
    - Most cases
        - Benign
        - Self-limiting

- Background
    - Abnormal lymph node
        - >1 cm
    - Most common cause
        - Viral URTI
    - Reactive nodes
        - May persist weeks to months

    - Acute bacterial lymphadenitis
        - Tender
        - Usually unilateral
        - May become fluctuant

- Assessment

- History
    - Onset/duration
    - Location
    - Growth/change in size
    - Colour
    - Pain
    - Skin changes
    - Neck movement restriction
    - Recent illness
    - Fever
    - Weight loss
    - Night sweats
    - Bruising
    - Other lymphadenopathy

    - Features of deep infection
        - Trismus
        - Muffled voice

    - TB exposure/travel
    - Animal exposure
        - Cats
    - Immunisation status
    - Dental disease
    - Response to antibiotics

- Examination

    - Characterise lymph node
        - Size
        - Location
        - Colour
        - Warmth
        - Mobility
        - Tenderness
        - Skin changes

    - Assess
        - Unilateral vs bilateral
        - Soft/rubbery/firm
        - Matted
        - Fluctuant
        - Discharging

    - Neck ROM

    - Examine other lymph node regions

    - Search for infection source
        - Scalp
        - Ear
        - Nose
        - Throat
        - Teeth

- Differential diagnosis

- Acute (<2 weeks)

- Viral lymphadenitis
    - Very common
    - ± tender
    - Unilateral or bilateral
    - Resolves with viral illness
    - Small risk secondary bacterial infection

- Acute bacterial lymphadenitis
    - Usually unilateral anterior cervical
    - Fever
    - Tender
    - Firm
    - Erythema
    - Reduced neck ROM

    - Common organisms
        - Staphylococcus aureus
        - Group A streptococcus
        - Group B streptococcus
            - Neonates
        - Anaerobes
            - Dental source

    - May progress to deep infection

- Kawasaki disease
    - Unilateral tender node
    - Associated Kawasaki features

- Persistent (2–6 weeks)
    - Usually viral
    - May remain unexplained

- Chronic (>6 weeks)

| Cause | Clinical features |
|---|---|
| EBV / CMV / Rubella | Generalised lymphadenopathy + hepatosplenomegaly |
| Mycobacterium tuberculosis | Non-tender nodes, TB exposure, systemic symptoms |
| Atypical mycobacteria | Chronic unilateral node, violaceous, usually <5 years |
| Bartonella henselae | Tender lymph nodes, often axillary |
| Toxoplasmosis | Non-suppurative generalised lymphadenopathy |
| Malignancy | Painless firm prolonged nodes, weight loss, night sweats, bruising, hepatosplenomegaly, mediastinal mass |
| Eczema | Prominent posterior cervical nodes |
| Rheumatological disease (JIA/SLE) | Rash, joint pain, conjunctival changes |

- Management

- Well child
    - Observation
    - Reassurance
    - No routine investigations

- Investigations

- Acute (<2 weeks)

    - Well child
        - None

    - Unwell child
        - Follow febrile child/Kawasaki pathway
        - Neck ultrasound
            - If abscess suspected
        - MCS
            - If I&D performed

- Persistent (2–6 weeks)

    - Consider
        - FBE + blood film
        - CRP
        - ESR
        - LDH
        - LFT

    - Serology
        - EBV
        - CMV
        - HIV
        - Toxoplasmosis
        - Bartonella

    - TB testing
        - TST
        - Quantiferon

    - CXR
        - If malignancy suspected

    - Neck ultrasound

    - CT/MRI
        - Pre-operative planning

    - Biopsy
        - Excisional biopsy
            - Gold standard
        - FNA
            - Less useful

- Treatment

- Most cases
    - Self-limiting
    - No treatment required

- Bacterial lymphadenitis

    - Well child
        - Oral antibiotics
        - Review in 48 hours

    - Unwell/failed oral therapy
        - IV antibiotics

    - Follow local antimicrobial guidelines

- Fluctuant lymph node
    - Failure to improve with IV antibiotics
        - Surgical consultation
            - Incision and drainage

    - Suspected mycobacterial infection
        - Excision preferred
        - Avoid sinus tract formation

- Consult paediatrics when
    - Neonate
    - Unwell child
    - Persistent despite antibiotics
    - Features suggestive of
        - Kawasaki disease
        - Malignancy
        - Rheumatological disease
